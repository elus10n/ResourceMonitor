# Linux System Monitor

Программный комплекс `Linux System Monitor` является системой мониторинга основных ресурсов 
операционной системы `Linux` в реальном времени. Он предназначен для сбора, обработки и 
предоставления актуальных данных об утилизации процессора, памяти и запущенных процессах 
через встроенный HTTP-интерфейс, обеспечивая простоту интеграции с внешними приложениями 
и системами мониторинга.

## Назначение и функциональные возможности

* **Мониторинг ресурсов в реальном времени**: Сбор и анализ данных об использовании CPU, 
оперативной памяти и активных процессов с периодическим обновлением статистики.
* **Парсинг системных интерфейсов**: Извлечение информации из `/proc/stat`, `/proc/meminfo` 
и `/proc/[pid]/stat` для получения точных показателей утилизации ресурсов.
* **Сетевой доступ**: Интегрированный легковесный веб-сервер на базе фреймворка `Crow` 
для выдачи результатов в формате `JSON`.
* **Устойчивость**: Корректная обработка исключений, обхождение недоступных процессов и 
автоматическое восстановление при ошибках чтения системных файлов.

## Структура проекта

Репозиторий организован по модульному принципу, разделяя логику парсинга системной информации, 
сетевого взаимодействия и координации многопоточной работы:

* **`backend/include/`** - заголовочные файлы интерфейсов и типов данных.
    * `modules.h` - описание структур данных для CPU, памяти, процессов и обратных вызовов логирования.
    * `parser.h` - интерфейс модуля для парсинга файлов `/proc`.
    * `server.h` - интерфейс `HTTP-сервера` на базе библиотеки `Crow`.
    * `orchestrator.h` - контроллер управления жизненным циклом приложения и синхронизацией потоков.
    * `logger.h` - вспомогательные инструменты для вывода логов в стандартный поток.
    * `data_manager.h` - интерфейс менеджера обработки и форматирования системных данных.
* **`backend/source/`** - реализация функциональных модулей.
    * `parser.cpp` - логика чтения и парсинга информации из файловой системы `/proc`.
    * `server.cpp` - реализация обработчиков HTTP-запросов и WebSocket-соединений для трансляции данных.
    * `data_manager.cpp` - логика подготовки и форматирования данных в JSON-формат.
* **`backend/libs/`** - внешние зависимости проекта (`header-only` библиотеки `crow_all.h` и `json.hpp`).
* **`static/`** - статические ресурсы веб-интерфейса (HTML, CSS, JavaScript).
* **`index.html`** - главная страница веб-интерфейса для отображения статистики.
* **`main.cpp`** - точка входа, инициализация системы и запуск оркестратора.
* **`CMakeLists.txt`** - конфигурационный файл системы сборки.

## Технический стек

Для реализации проекта использован современный инструментарий разработки на C++:

* **Стандарт языка**: C++20.
* **Библиотеки**: `nlohmann/json` для сериализации данных, `Crow` для HTTP-сервера 
и веб-фреймворка, `ASIO` для асинхронных операций ввода-вывода.
* **Многопоточность**: Реализована модель с отдельным потоком для сервера и основным 
циклом сбора данных с синхронизацией через мьютексы и атомарные переменные.

## Инструкция по сборке

Для сборки проекта требуется компилятор с поддержкой стандарта **C++20** и установленная 
система **CMake** версии 3.22 или выше.

### Сборка через CMake

1. Создайте директорию для сборки и перейдите в нее:
```bash
mkdir build
cd build
```

2. Сгенерируйте файлы сборки:
```bash
cmake .. -DCMAKE_BUILD_TYPE=Release
```

3. Скомпилируйте проект:
```bash
cmake --build . --config Release
```

После завершения процесса в директории `build` будет создан исполняемый файл `system_monitor`.

## Запуск

Запуск программы осуществляется следующей командой:
```bash
./system_monitor
```

По умолчанию HTTP-сервер запускается на порту `8080`. Для доступа к данным мониторинга 
откройте в браузере адрес `http://localhost:8080` или используйте API-запросы для получения 
данных в формате JSON.
